# Genesis Engine v5.0-alpha — Measured Substrate + Four Extensions

**Containment boundary remains absolute.** All strategy logic still executes only inside the fuel-metered bytecode VM.

## What is now implemented

| Layer | Status |
|-------|--------|
| Genetic expression-tree evolution | Live |
| Bytecode VM (fuel + stack + compile-depth limits) | Live & measured |
| Causal / intervention terminals | Live (synthetic DAG) |
| Regime-shift world model | Live |
| Strategy ensemble / portfolio | Live |
| Immutable audit trail | Live |

### Feature vector (16 terminals)

```
0-9   mid, spread, imbalance, volume, rsi, zscore, momentum, volatility, time_frac, prev_signal
10-13 do_imbalance, causal_mid, shock, confounder     ← causal / intervention
14-15 regime, regime_age                              ← regime indicators
```

### Causal sketch (synthetic)

```
confounder ──► imbalance ──► mid
shock      ──► imbalance
do(imbalance) ──► causal_mid   (interventional feature the genome can read)
```

Strategies can therefore condition on both observational and interventional signals. Everything remains pure floats; nothing escapes the VM.

### Regime shifts

Markets switch between calm and stress mid-path (volatility, shock frequency, mean-reversion strength change). Strategies that ignore `regime` / `regime_age` under-perform.

### Portfolio layer

Equal-weight (or custom) combination of hall-of-fame genomes. Reports portfolio Sharpe, mean return, max drawdown, and average pairwise signal correlation.

### Audit trail

Append-only JSONL (`audit_log.jsonl`). Each evaluation records genome id, source snippet, bytecode hash, n_ops, fitness, fuel limit, and a hash chain.

## Run

```bash
python3 genetic_strategy_engine.py   # full demo (evolution + portfolio + audit)
python3 measure_boundary.py          # original containment stress suite
```

## Still architecture (not implemented)

Market Genesis, live capital, multi-agent wallets, self-rewriting of the host, real oracle duties, external data feeds, quantum annealing, etc.

## Design rule

Ship enforceable features. The four extensions above stay inside the measured containment boundary. Everything else waits.
