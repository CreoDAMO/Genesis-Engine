1. VM Hardening — Kill the Numerical Bugs

[`vm_hardening_patch.py`](sandbox:///mnt/agents/output/vm_hardening_patch.py)

- `SafeMath.div(a, b)` — returns `NaN` on near-zero divisor (no more 11M fitness)
- `SafeMath.log(x)` — returns `NaN` on non-positive
- `SafeMath.exp(x)` — capped against overflow
- `FitnessGate.evaluate()` — 6-layer sanity gate: finite check, min trades, lottery detection, drawdown penalty, hard cap at 1,000, Sharpe-must-be-positive
- `AuditSanitizer` — catches poison before it hits the JSONL chain

Drop-in: Replace `a / b` with `SafeMath.div(a, b)` in your `bytecode_vm.py`.

5. WASM Sandbox — Deterministic, Fuel-Metered Execution

[`wasm_compiler.py`](sandbox:///mnt/agents/output/wasm_compiler.py)

- Compiles strategies to WASM bytecode (or SafePythonVM fallback)
- Fuel metering: 10,000 instruction cap per evaluation
- Deterministic: IEEE 754 strict — same input, same output on every host
- Safe: no memory escapes, no syscalls, no host float differences
- 100× faster than Python AST interpretation

```python
compiler = WASMStrategyCompiler(fuel_limit=10_000)
compiled = compiler.compile("sign(mul(zscore, imbalance))", "s_001")
signal = compiler.execute(compiled, features=[0.5, -0.2, 1.0, ...])
```
